The PayPathIQ inbound API lets an approved source Integration create and maintain Parties, Receivables, and immutable Payment observations.

<Warning>
  Use sandbox with synthetic data while PayPathIQ completes your approved production activation. Production recovery remains disabled until the representative cohort is reconciled and approved.
</Warning>

The API validates and projects every accepted request synchronously. A successful response means the record is PayPathIQ state. Data that cannot be projected safely is rejected with a typed error.

## V1 at a glance

- One resource per request; no collection or bulk routes.
- Stable, non-sensitive external IDs in URLs.
- Full replacement with `PUT`; partial changes with JSON Merge Patch.
- Integration-owned Bearer keys with server-side Client grants.
- A closed `credit_union.v1` profile. No arbitrary metadata.

The downloadable OpenAPI 3.1 document is the authoritative wire contract.
